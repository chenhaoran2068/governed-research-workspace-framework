# V0.5.0 Release Gate

Status: candidate gate.

Release may proceed only after the exact candidate passes local contract tests,
public-boundary review, protected-main review, and the repository CI matrix.
The release must use a separately verified annotated tag and matching GitHub
Release.

This candidate adds an optional Research Program index contract. It must not
contain a real Study, Research Program, local workspace path, data, credential,
manuscript, result, or private adoption record. It does not create, migrate,
or register a Research Program in a user workspace.
