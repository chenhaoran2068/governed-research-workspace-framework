# Release Notes V0.3.0

Status: candidate notes; not proof of publication.

## Added

- An opt-in generic knowledge-service manifest contract under `Knowledge/`.
- A blank manifest template and a synthetic registered-service example.
- Explicit consumer matching between workspace registration, service manifest,
  and System optional-service declaration.

## Unchanged

- Workspace-manifest schema version `1`.
- Empty bootstrap behavior: no service is created or registered.
- Existing workspaces without a knowledge service.
- No source access, source-artifact retention, project authority, or automatic
  installation capability.
